# Task Plot Brief

## Task

- Title: Cyberball Task
- Construct: social inclusion / ostracism / social exclusion
- Paradigm: three-player virtual ball-toss game with condition-specific toss policy.

## Rows

- Inclusion: avatars continue to include the participant in toss circulation.
- Exclusion early: participant may receive initial tosses.
- Exclusion ostracism: avatars toss only to each other after the initial receives.

## Trial Timeline

1. Avatar turn: 800-1200 ms simulated decision delay when an avatar holds the ball.
2. Participant decision: 2500 ms when participant holds the ball. Press F for Player A, J for Player B.
3. Toss animation: 450 ms ball transfer to the selected or policy-determined target.
4. Post-toss gap: 250 ms brief interval before the next toss event.

## Notes

- Inclusion uses avatar-to-participant passing probability 0.33.
- Exclusion allows 2 initial participant receives, then switches to avatar-only passing.
- Participant timeout uses random fallback target selection.
